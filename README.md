A modern, responsive personal portfolio web page designed and built completely from scratch using pure HTML5 and CSS3.

## 📌 Project Overview
This web page represents my first hands-on project in web development. The main goal of this build was to learn how to structure a clean web page using semantic HTML tags and style it with modern CSS layout techniques.

The design uses a sleek dark mode color scheme paired with bold crimson accents to create a professional visual hierarchy.

---

## ✨ Key Features
* **Multi-Column Layout:** Built using CSS Flexbox to organize content into distinct visual sections, including a left sidebar and main content area.
* **Vertical Sidebar Typography:** Features customized vertical rotated text on the sidebar for a unique aesthetic touch.
* **Dark Theme Design:** High-contrast dark backdrop paired with crimson highlights for clear readability.
* **Interactive Credentials Box:** A dedicated, scrollable section created to display certifications, courses, and project experience smoothly.

---

## 🛠️ Built With
* **HTML5:** Used for page structure and semantic elements (`<aside>`, `<main>`, `<nav>`).
* **CSS3:** Used for visual styling, layout positioning, custom fonts, and Flexbox alignment.
